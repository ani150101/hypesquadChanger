# Vencord HypeSquad Changer Plugin

[![Vencord Plugin](https://img.shields.io/badge/Vencord-Plugin-7289DA?style=for-the-badge&logo=discord&logoColor=white)](https://github.com/Vendicated/Vencord)
[![Discord](https://img.shields.io/badge/Mr.%20Robot-%235865F2?style=for-the-badge&logo=discord&logoColor=white)](https://discord.com/users/426234414255570959)

A lightweight, custom **Vencord plugin** that allows you to easily change or remove your Discord HypeSquad house directly from your client using a built-in slash command. 

If you are looking for how to change your Discord HypeSquad house (Bravery, Brilliance, or Balance) without retaking the quiz, or how to remove the HypeSquad badge entirely, this Vencord plugin is exactly what you need.

## ✨ Features

* **Slash Command Integration:** Seamlessly integrated into Discord's chat interface via the `/hypesquad` command.
* **Instant Switching:** Instantly swap between the House of **Bravery**, **Brilliance**, and **Balance**.
* **Remove Badge Option:** Includes a clean `Leave HypeSquad` option to completely remove the badge from your profile.
* **Token Secure:** Automatically hooks into Vencord's internal `TokenStore`. No need to manually copy, paste, or hardcode your Discord token.

## 🚀 Installation

Since this is a source-level Vencord plugin, you will need to inject it into your local Vencord build.

1. Ensure you have the [Vencord source code](https://github.com/Vendicated/Vencord) cloned on your machine.
2. Navigate to the plugins directory: `src/plugins/`
3. Clone or download this repository into a new folder named `hypesquadChanger`
